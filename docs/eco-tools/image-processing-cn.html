图像处理

图像处理与细胞分割是时空转录组学中至关重要的上游步骤。以下是兼容 Stereo-seq 图像分析流程的工具，分为 时空自主研发工具（STOmics Developed）（原生支持时空专有图像格式）与 社区常用工具（Community Tools）（需输入标准格式图像的通用模型）。

想要了解不同分割模型在 Stereo-seq 数据集上的性能表现与对比评测，欢迎阅读我们的图像分割benchmark博文。

社区开发工具

生物图像与数字病理社区广泛使用的图像分析工具。这些通用工具可用于处理导出的组织图像，或顺畅衔接至 Stereo-seq 分析流程中。

注意：STOmics 仅提供此工具列表供参考，不对社区开发工具提供官方技术支持或开发维护。我们不对其性能表现、稳定性或兼容性做任何保证。如需技术支持、问题反馈或功能建议，请直接联系对应工具的开发者或查阅其官方代码仓库。

细胞分割

预训练深度学习模型与算法框架，支持跨不同组织模态实现自动化的单细胞与细胞核分割。

想要了解如何利用第三方社区工具的分割结果生成 cellbin 数据，请查阅我们的教程。

  • 数据衔接：可通过图形界面（GUI）或 Python API 对多色染色的组织图像进行单细胞或细胞核分割，随后将标准 Cell Mask 导出为 TIFF 或 GeoJSON 格式，接入时空分析工具以实现高精度的 cell bin 分割。
