高级分析

为了提供全面的分析工作流，我们精选了一系列常用及与 Stereo-seq 数据兼容的生态工具。这些工具分为 STOmics 开发（数据格式无缝兼容与优化）与 常用社区工具（需进行标准数据格式转换）。

STOmics 开发工具

本章节中的工具对 Stereo-seq 数据格式提供原生支持，确保无缝的数据流转

Stereo Data Analysis Solution (SDAS) Stereo3D
CLI Linux Open Source Python 3D Alignment Open Source
GitHub GitHub
  • 专为 Stereo-seq 数据打造的 Linux 命令行工具包，开箱即用，集成了多项经过实测优化的算法。

  • 核心功能与价值：

    • 算法深度适配：精选 31 种在 Stereo-seq 数据上实测过的算法，并配有分析指南，确保分析结果稳定可靠。
    • 开箱即用，省去环境配置：零配置 Linux 软件包，无需手动搭建复杂的 R、Python 或 CUDA 环境，彻底避免环境冲突。
    • 14 个模块与 31 种算法：将 31 种常用空间算法整合为 14 个功能模块，涵盖细胞注释、细胞通讯、空间域分析等主流分析场景。
    • 原生兼容时空生态：可直接读取 SAW 输出的 .h5ad 与 .h5mu 文件（ saw aggr 整合的多样本数据集），同时兼容标准的 AnnData 和 Seurat 对象。
    • 工作流价值：用一套规范、高效的分析流程替代零散的手写脚本，帮助研究人员快速完成数据梳理与生物学探索。

  • 基于 anndata 构建的单细胞基因表达数据分析工具包，具备良好的扩展性。
  • 数据衔接：可直接使用 SAW / StereoMap 生成的 .h5ad 格式矩阵数据，导入 Scanpy 后即可开展降维、聚类与可视化分析。
  • 非常热门的 R 语言工具包，广泛应用于单细胞与空间转录组数据分析。
  • 数据对接：您可将 .h5ad 数据转换为 Seurat Object，从而借助 R 语言丰富的工具生态，进行深入的空间特征挖掘。
  • 专为空间转录组数据定量与时空建模设计的开源 Python 框架，针对 Stereo-seq 等高分辨率、大视野技术进行了深度优化。
  • 数据衔接：SAW / StereoMap 生成的 .h5ad 格式矩阵，可直接导入 Spateo 开展高级 3D 重建、细胞分割以及形态学向量场分析。
Stereopy Giotto Suite Spateo
Python Toolkit Open Source R Toolkit Open Source Python Toolkit Open Source

  • 专注于空间转录组下游分析的 Python 工具包，功能全面且具备良好的扩展性，内置丰富的空间高级算法并支持多样本分析。
  • 数据衔接：原生支持直接读取 SAW / StereoMap 生成的 .h5ad、.gef 或 .h5mu 文件（ saw aggr 整合的多样本数据集），顺畅开启细胞聚类、组织区域识别、细胞间通讯及多样本对比等下游分析。
  • 功能全面的多模态空间组学分析 R 包，针对 Stereo-seq 进行了原生数据支持与多尺度分析能力的深度优化。
  • 数据衔接：可直接解析 Stereo-seq 的 .gef 矩阵文件，或通过互操作层接收 .h5ad 文件。支持从 bin/细胞层级到亚细胞 Bin1 数据的多尺度分析，方便开展下游空间域划分与细胞相互作用挖掘。
  • 基于 Scanpy 和 AnnData 构建的 Python 框架，专为空间组学数据的分析与可视化设计，主打高级空间图结构分析以及图像与转录组的联合分析。
  • 数据衔接：直接接收由 SAW / StereoMap 转换的 .h5ad 文件。可将细胞空间坐标构建为空间图，进而开展邻域富集、空间共现以及配体-受体相互作用等深度分析。
